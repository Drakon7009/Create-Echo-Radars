# Create: Echo Radars

Аддон для NeoForge 1.21.1, добавляющий кинетический подводный сонар для Create: Radars.

## Зависимости

- Create 6.0.10
- Create: Radars 0.4.9.4
- Create Big Cannons 5.11.3 и Ritchie's Projectile Library 2.1.2 (требуются самим Create: Radars)
- Sable 1.2.1 — необязательно; при наличии сканируются его движущиеся конструкции

## Использование

1. Установите сонар так, чтобы прямоугольная головка на передней стороне находилась в воде.
2. Убедитесь, что излучатель на передней стороне находится в воде. Кинетическое питание не требуется.
3. Правым кликом откройте настройки дальности и горизонтального сектора.
4. Подключите сонар к Network Filterer и монитору штатным Data Link из Create: Radars. Сонар занимает слот стационарного радара.
5. Монитор автоматически переключится на веерную развёртку: вершина сектора — сонар, дуги показывают дальность, а радиальные линии — азимут.

Каждый импульс состоит из настраиваемого числа горизонтальных лучей и пяти вертикальных подлучей. Лучи останавливаются на первом препятствии, создавая акустическую тень; старый кадр плавно гаснет под новым. Палитра, усиление и зернистость подтверждённых отражений настраиваются через кнопку «Настройки» мода в меню NeoForge. Число лучей, шаг за тик и лимит асинхронного чтения чанков находятся в серверном config.
